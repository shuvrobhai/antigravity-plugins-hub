# Example Skill

This skill demonstrates the canonical structure of an Antigravity agent workflow.

## When to Use
Use this skill when initializing or verifying an example plugin component.

## Workflow
1. Inspect the workspace plugin manifest (`plugin.json`).
2. Verify that all declared subagents and rules match repository conventions.
3. Output a structured validation summary.
